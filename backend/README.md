# Formwise Backend

Phase 2 backend foundation for profile and secure document-vault capabilities.

## Phase 2 scope

- API foundation
- Profile model/service boundaries
- Address and education model boundaries
- Secure document metadata model
- Storage abstraction
- Ownership/authorization boundaries
- Audit-event boundaries

OCR, embeddings, LLM agents, Playwright automation, form mapping, OTP/CAPTCHA/payment, and final submission are intentionally out of scope for Phase 2.
